WebSSH

一个在本地或自托管环境中运行的浏览器 SSH 工具，集成多会话终端、SFTP 文件传输和已保存连接管理。

📦 下载 v0.1.3 💻 查看源码

⚠️ 这是产品展示页，不提供在线 SSH 服务。请下载并在自己的设备或受控服务器上运行。

FEATURES

强大而安全的功能

🖥️

多会话终端

在独立标签页中保持多个 SSH 会话，快速切换并同步终端尺寸。

🔐

安全的连接保存

保存的连接配置使用 AES-256-GCM 本地加密，支持密码和 OpenSSH 私钥认证。

📁

SFTP 文件传输

上传本地目录，浏览远程目录并下载一个或多个文件。

📦

多平台交付

提供 Windows 便携版、Docker 部署方式和 fnOS 原生 FPK 安装包。

INTERFACE

为日常运维而设计

深色与浅色主题、字体颜色、字号及背景设置均可即时调整。保存常用连接后，可一键快速重连。

SECURITY

请在可信环境中使用

WebSSH 不提供用户登录、TLS 或公网访问保护。不要直接暴露到公网；远程访问请使用 VPN，或部署在具备 HTTPS、身份验证和访问控制的反向代理之后。
