WHY WEBSSH

少一点切换，
多一点专注。

WebSSH 将日常远程运维需要的终端、连接资料和文件操作整合在一个清晰的浏览器界面中。无需把服务暴露为在线 SSH，只需在你信任的环境中启动它。

FEATURES

为日常运维准备的工具

从连接服务器到收发文件，每一步都保持简单、直观。

01

多会话终端

以标签页同时保持多个 SSH 会话。点击切换，关闭标签即断开连接，并自动同步终端尺寸。

⌘
02

连接配置管理

保存、置顶或删除常用服务器。支持密码与 OpenSSH 私钥认证，连接信息一目了然。

◎
03

SFTP 文件传输

选择远程目录后上传本地目录；也能浏览远程文件并一次下载多个文件。

可调整的工作环境

深色与浅色主题、字号、字体颜色和背景图片均可按自己的习惯调整。

实时连接状态

面向现代桌面与移动浏览器设计，常用设置会保存到服务端，不会因清理浏览器缓存而丢失。

GET STARTED

三步开始连接

无论使用便携版、Docker 还是 fnOS，启动后都可以在浏览器中完成后续操作。

  1. 1
    启动 WebSSH

    Windows 便携版解压后双击运行；Docker 和 fnOS 按部署说明启动。随后在浏览器打开应用地址。

  2. 2
    新建并保存连接

    填写主机、端口和用户名，选择密码或 OpenSSH 私钥认证。确认可用后，可将常用服务器保存并置顶。

  3. 3
    连接并开始工作

    打开终端标签执行命令；需要传输文件时，使用顶部的上传或下载入口进行 SFTP 操作。

✓

SECURITY BY DESIGN

你的连接资料，留在你掌控的环境中。

已保存的 SSH 连接配置采用 AES-256-GCM 加密存储，并支持旧配置自动迁移。WebSSH 不提供用户登录、TLS 或公网访问保护，请勿直接暴露至公网；远程访问建议配合 VPN 或具备 HTTPS、身份验证与访问控制的反向代理。
