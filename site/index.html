LOCAL-FIRST SSH WORKSPACE

在浏览器中，
轻松管理 SSH。

WebSSH 是一个本地优先的 SSH 工具，提供多会话终端、连接管理和 SFTP 文件传输。

下载最新版本 查看使用说明

仅在你的设备或受控服务器中运行，不提供在线 SSH 服务。

FEATURES

专注于日常运维

⌘

多会话终端

通过标签页同时管理多个 SSH 会话，快速切换、即时操作。

⌁

SFTP 文件传输

上传目录、浏览远程文件，并支持一次下载多个文件。

⌾

安全保存连接

连接配置采用 AES-256-GCM 加密，支持密码与 OpenSSH 私钥。

□

多平台运行

提供 Windows 便携版、Docker 部署与 fnOS 原生安装包。

安全提示

WebSSH 不包含公网访问保护。请勿直接暴露至公网；远程访问建议使用 VPN，或配置 HTTPS、身份验证和访问控制。
