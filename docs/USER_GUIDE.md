# WebSSH 用户手册

WebSSH 是一个轻量级的浏览器 SSH 终端，支持多标签会话、连接信息保存、文件上传下载、个性化外观设置，可在 Windows 直接运行或在 fnOS（飞牛 NAS）上一键安装。

本手册面向**最终用户**，覆盖安装、首次使用、连接管理、终端操作与个性化设置。

---

## 1. 安装与启动

### 1.1 在 Windows 上运行

1. 从 [GitHub Releases](https://github.com/example-org/webssh/releases) 下载 `WebSSH-x.y.z-Windows.zip`
2. 解压到任意目录
3. 双击 `WebSSH.exe` 即可启动
4. 浏览器自动打开 `http://127.0.0.1:1314`（若未自动打开，请手动访问）

> Windows 便携版默认仅监听 `127.0.0.1:1314`。如需局域网访问，请通过 `WEBSSH_HOST=0.0.0.0` 显式配置，并配合访问控制措施。

### 1.2 在 fnOS（飞牛 NAS）上安装

1. 在 fnOS 的「应用中心」搜索 **WebSSH** 并安装
2. 安装完成后在桌面或应用列表中启动
3. 浏览器访问 fnOS 自动分配的应用地址（通常形如 `http://NAS-IP:端口`）

## 3. 创建 SSH 连接

点击「+ 新建连接」或顶部「+」按钮，右侧滑出**连接抽屉**。

### 3.1 使用密码连接

![新建连接 - 密码模式](./screenshots/02-new-connection.png)

填写字段：

| 字段 | 必填 | 说明 |
|------|------|------|
| 名称 | 否 | 连接别名，便于在「保存连接」列表中识别（如「生产服务器」） |
| 主机 | **是** | SSH 服务器地址（域名或 IP） |
| 端口 | 否 | 默认 22 |
| 用户 | **是** | SSH 登录用户名 |
| 密码 | **是** | SSH 登录密码 |

填写后点击底部 **「连接（锤子图标）」** 按钮即可建立会话。点击「保存（💾）」图标可保存连接以便下次复用。

### 3.2 使用私钥连接

切换到「私钥」标签页：

![新建连接 - 私钥模式](./screenshots/03-new-connection-key.png)

- 将 OpenSSH 格式的私钥内容粘贴到「**私钥内容**」文本框
- 如私钥设置了密码短语，填写到「**私钥口令**」
- 点击连接按钮即可

> 支持 OpenSSH（`-----BEGIN OPENSSH PRIVATE KEY-----`）格式私钥。

## 4. 管理保存的连接

抽屉顶部会自动列出**之前保存过的连接**：

![保存的连接列表](./screenshots/09-saved-connections.png)

- 顶部的「保存连接」列表展示了所有历史连接
- 每条连接旁有「置顶 ★」标识——置顶的连接会出现在最上方，便于快速访问
- 列表项旁有两个操作：
  - **📌**（橙色）：切换置顶状态
  - **🗑**（垃圾桶）：删除该连接

点击任意一条保存的连接，即可快速重连。

## 5. 终端使用

连接建立后，会自动打开一个**终端标签页**，输入 SSH 凭据后即可像本地终端一样操作远程主机。

### 5.1 多标签与会话管理

- 顶栏的「标签栏」会显示所有打开的会话
- 点击标签可切换；点击 `×` 可关闭单个会话
- 多个会话同时保持，互不干扰

### 5.2 文件上传到远程主机

1. 点击顶部「↑ 上传」按钮
2. 在弹出的对话框中输入**远程目标目录**（如 `/var/www/app`）
3. 点击「选择目录」选择**本地目录**——该目录下的所有文件会按目录结构上传
4. 等待进度条完成

![上传文件对话框](./screenshots/06-upload-picker.png)

> 上传过程中可以继续在终端中操作，不会被阻塞。

### 5.3 下载远程文件到本地

1. 点击顶部「↓ 下载」按钮
2. 输入**远程目录**（如 `/var/log`）并点击「读取目录」
3. 在文件列表中选择要下载的文件（支持多选）
4. 文件会下载到浏览器默认下载目录

![下载文件对话框](./screenshots/07-download-picker.png)

## 6. 个性化设置

### 6.1 主题切换（深色 / 浅色）

点击顶栏「A 主题」按钮即可在深色与浅色主题间切换。

**深色主题**（默认）：

![深色主题主界面](./screenshots/01-home.png)

**浅色主题**：

![浅色主题主界面](./screenshots/08-light-theme.png)

> 切换主题会立即在终端背景、面板、按钮、字体颜色上全面生效。

### 6.2 终端字号

点击顶栏「☀ 字号」按钮，弹出**字号设置菜单**，拖动滑块即可实时调节终端内字体大小（范围 10–24px）。

### 6.3 终端字体颜色

点击顶栏「Aa 字体」按钮，弹出**字体设置菜单**：

![字体设置菜单](./screenshots/04-font-settings.png)

菜单包含：

- **字号滑块**：调整终端字号
- **字体颜色选择器**：自定义终端文字前景色（默认跟随主题；自定义后会覆盖主题色）

调整会立即应用到当前所有打开的终端会话。

### 6.4 背景图片

点击顶栏「🖼 外观」按钮，弹出**背景设置菜单**：

![背景设置菜单](./screenshots/05-background-settings.png)

- **上传图片**：从本地上传一张图片作为应用背景
- **透明度滑块**：调整背景图的不透明度（让终端仍清晰可见）
- **移除按钮**：清除已设置的背景

**标题后的状态指示灯**：
- 灰色圆点 = 未设置背景
- 亮色圆点（青色/薄荷绿）= 已设置背景

## 7. 常见问题（FAQ）

**Q1：忘记保存连接就关闭了浏览器，下次还能找回吗？**
A：不能。所有会话状态（未保存的连接、打开的终端标签）仅存在于当前浏览器会话中，刷新或关闭浏览器后会丢失。建议常用连接保存下来。

**Q2：私钥连接失败，提示 "invalid private key"？**
A：仅支持 OpenSSH 格式（`-----BEGIN OPENSSH PRIVATE KEY-----`）。如你持有的是传统 RSA 格式（如 `-----BEGIN RSA PRIVATE KEY-----`），请用 `ssh-keygen -p -m PEM -f <key>` 转换。

**Q3：上传/下载文件大小有限制吗？**
A：单文件最大 200MB，由服务端 `multer` 限制。如需更大文件，请直接在终端使用 `scp` / `rsync`。

**Q4：如何在局域网其他设备访问 WebSSH？**
A：服务默认监听 `0.0.0.0:1314`，只要两台设备在同一局域网，访问 `http://<运行WebSSH的设备IP>:1314` 即可。如路由器启用了防火墙/隔离，请在防火墙中放行 1314 端口。

**Q5：关闭终端标签会断开 SSH 连接吗？**
A：会。关闭标签会立即终止对应的 SSH 进程。若仅希望切换标签查看其他会话，请点击标签切换而非关闭。

**Q6：修改了字号/字体颜色后未生效？**
A：调整设置后会立刻对所有打开的会话生效。若新建连接后才设置，已存在的会话不会自动刷新——请重新打开一个终端会话查看效果。

**Q7：背景图片上传后，应用界面变得很暗看不清文字？**
A：请降低「透明度」滑块的数值（即降低背景不透明度，让背景更透明）。推荐设置在 30–50% 之间。

**Q8：如何完全卸载？**
- **Windows**：直接删除解压目录即可（绿色软件，无注册表残留）。
- **fnOS**：在「应用中心」找到 WebSSH，点击卸载。
